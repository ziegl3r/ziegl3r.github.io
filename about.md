# About

I'm Cory. I'm studying for Anthropic's **Claude Certified Architect – Foundations (CCA-F)** certification, and building **[CarTechTutor](https://cartechtutor.com)** — AI-powered tools for automotive dealerships — on the side. This site is where both of those live in public.

## How I work

- **Build:** VS Code + Claude Code, "vibecoding" style — most projects start as a conversation and end as a commit.
- **Record:** Sessions get captured on Loom.
- **Write:** The canonical write-up lands here first, on GitHub Pages.
- **Repurpose:** Posts get cut down into X threads; Loom recordings become YouTube footage. Every other channel links back here.

## On CCA-F

I'm working through Anthropic's AI Fluency Framework Foundations course — the 4D Framework (**D**elegation, **D**escription, **D**iscernment, **D**iligence) and the three human-AI collaboration modes (Automation, Augmentation, Agency). Study notes and the reasoning behind each one show up on the [blog](/blog/) as I go, alongside the shipped tools that put the framework into practice.

## On CarTechTutor

CarTechTutor is a separate brand from my day job, with a clean line between the two — the tools here are built and owned independently. Five tools are already built and demoed live at Lexus Carlsbad; the current focus is packaging them to pitch to other dealers. Progress lands in the [portfolio](/portfolio/).
